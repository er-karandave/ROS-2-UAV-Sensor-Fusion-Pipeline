# ROS-2-UAV-Sensor-Fusion-Pipeline
ROS 2 (Humble) simulation pipeline for autonomous UAV navigation. Implements an Extended Kalman Filter (EKF) for multi-sensor fusion (IMU, LiDAR, Depth Camera) in Gazebo to reduce positional drift.
ROS 2 Humble, Gazebo, Python, C++, Extended Kalman Filter (EKF), LiDAR, IMU, Nav2.
